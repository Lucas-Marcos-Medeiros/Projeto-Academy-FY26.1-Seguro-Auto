# Projeto Academy FY26.1 - Seguro Auto

Este repositório centraliza o **código-fonte, documentação e artefatos** de um ecossistema que combina:
- **Engenharia de Dados (ETL)** e **Análise de Dados** realizadas no **Databricks**;
- **Modelagem e Treinamento de IA/ML** em ambientes Python locais;
- **APIs e Integrações Inteligentes** (LangChain, Streamlit, etc.);
- **Controle de versões e colaboração** para equipes multidisciplinares.
